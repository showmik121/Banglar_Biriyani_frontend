# Banglar Biriyani — Frontend (demo)

React 19 + Vite + Tailwind CSS v4 storefront and admin UI.

```
npm install
npm run dev     # http://localhost:5173
npm run build
```

The app calls a backend at `/api/*`. In dev, requests are proxied to
`VITE_API_TARGET` (default `http://localhost:3001`). The backend is not part of this repo.
